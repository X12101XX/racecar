## 文档结构建议（与评分表对应）

技术报告占总成绩 20%，要求"以案例的形式书写，最少不低于 5 个案例，每个案例最高 4 分"，
评分项为：案例创新性（0~1）、案例实用性（0~1）、案例复杂度（0~1）、案例复现性（0~1，
"结合提交的源码可成功复现则该项满分"）。

| 章节 | 建议内容 | 现成素材 |
| --- | --- | --- |
| 一、赛题理解与总体方案 | 任务流程拆解、系统架构图、软硬件选型 | `docs/01_系统架构与算法.md` 第 1、8 节 |
| 二、硬件与平台 | 小车尺寸/传感器/算力平台、安装位置 | `docs/02_车辆部署指南.md` 第 1~3 节 |
| 三、算法设计 | 视觉、雷达聚类、融合建图、定位、规划、控制 | `docs/01_系统架构与算法.md` 第 2~7 节 |
| 四、技术案例（≥5 个） | 每个案例：现象 → 定位过程 → 方案 → 代码位置 → 可复现验证数据 | `docs/04_技术文档案例.md`（已有 7 个） |
| 五、实验与测试 | 批量随机场地成功率、用时分布、感知召回/精度、失败分析 | `docs/03_测试报告.md` + `output/stress/*.json` |
| 六、现场流程与安全 | 发车流程、播报、急停与兜底策略、异常处理 | `docs/02_车辆部署指南.md` 第 2、4、6、7 节 |
| 七、复现说明 | 环境依赖、一键命令、配置文件说明 | `README.md` 第 1、9 节 |
